# ADR-0001：qa-case-xlsx 独立本地交付

- 状态：Accepted；飞书与网络边界已由 ADR-0002 部分取代
- 日期：2026-08-14
- 决策人：用户与 Codex

## 背景

原 `qa-case-xlsx` 以 `qa-case` 基线和飞书在线模板为运行前提，并携带 QAWORK、在线文档、历史学习候选和在线交付语义。用户需要它离开 QAWORK 后仍可使用，只读取本次上传的本地策划案，并生成本地 Excel 测试用例。

## 决策

1. 将 `D:\project\qa-case-xlsx` 作为唯一独立源目录，`SKILL.md` 直接位于根目录。
2. 内联 `qa-case` 的通用蓝图、GR-01～GR-08 完整性矩阵、原子拆分、需求追溯、项目路由和人话化能力。
3. 保留 50 条已发布个人规则、稳定 ID、Schema、索引、哈希发布清单和必要模块快照；删除候选 JSONL、在线证据索引、历史规则目录和自动学习。
4. 输入仅限用户本次上传或明确指定的本地 DOCX/PDF/XLSX/Markdown/TXT/PNG/JPG；外链只登记，不访问。
5. 输出为离线模板生成的固定 A:J 本地工作簿和 `audit/` 审计目录；不读写飞书，不调用 Jira、Code Ask、MasterGo、KB 或 QAWORK 流程。
6. 来源不完整或存在 pending/冲突时生成“待确认草稿”；没有 confirmed 业务事实时不生成工作簿；只有 `pending=0` 才使用正式文件名。
7. 独立源目录初始化本地 Git，但不配置 remote、不 commit、不 push。通过全部验收后，先备份旧安装包，再同步到用户级 Skill 目录并校验逐文件哈希。

## 影响

### 正面

- Skill 可在 QAWORK 之外和断网环境中运行。
- 业务事实、规则补充和最终用例之间有本地可复核链路。
- 本地 `.xlsx` 成为唯一正式交付，不再依赖在线模板或在线权限。
- 规则包不再携带外部 token、URL 和不可读历史来源。

### 代价

- Codex 仍需使用 bundled 文档/PDF/表格运行时读取复杂文件和生成工作簿。
- 图片、扫描 PDF 和 DOCX 浮动对象需要实际视觉复核，不能只依赖文本提取器。
- 失去自动历史学习；规则变化必须显式修改、校验并重建发布清单。

## 被否决的方案

- 继续从 `qa-case` 运行时调用：无法满足离开 QAWORK 可用。
- 保留飞书读取但只取消写入：仍有在线权限和网络依赖。
- 只输出 CSV：不能保留确认的模板、公式、校验和视觉交付要求。
- 把全部项目风险转换为新增正式规则：会破坏现有 50 条稳定 ID/数量契约；改为项目参考按证据触发。
