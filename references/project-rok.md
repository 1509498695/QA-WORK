# ROK 离线项目风险参考

仅用于 ROK / 万国觉醒，且只在源包出现相应机制时触发。

## 风险矩阵

- 城市与建筑：建筑状态、队列占用、前置建筑、升级中断、完成后城市状态和战力变化。
- 统帅与部队：统帅资格、主副将、兵种、队列、行军状态、伤兵/死亡、回城后的可见结果。
- 世界地图：目标可见性、距离/区域限制、占领归属、行军冲突、目标消失或迁移后的处理。
- 联盟：成员/官职权限、联盟范围、多人并发、退出/踢出/解散后的状态与资源归属。
- 活动与赛季：王国/赛季阶段、资格、排行榜、积分、结算、跨阶段继承或清理。
- 道具与奖励：背包、邮件、资源上限、重复领取、到账延迟、重登后的结果。

## 组合控制

只选择能改变预期结果的最小组合。服务器、兵种、统帅、联盟身份、活动阶段不得无证据全排列。
