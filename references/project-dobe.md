# Dobe 离线项目风险参考

仅用于 Dobe，且只在源包出现相应机制时触发。

## 风险矩阵

- 入口与资格：可见/不可见、可用/禁用、角色与资源条件、首次与重复进入。
- 核心循环：开始、进行中、成功、失败、取消、退出、重新进入。
- 状态与数据：初始值、变更、上下限、累计、刷新、重登/切换后的保存与隔离。
- 奖励与消耗：扣除时机、到账位置、容量上限、重复领取、失败回滚。
- 活动与任务：开放周期、阶段、进度、结算、刷新和过期。
- UI 与引导：文案、按钮态、提示、遮挡、流程中断与恢复。

## 组合控制

项目资料不足时保持 generic，不借用其他项目的专属对象、名词或生命周期。
