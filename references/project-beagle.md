# Beagle 离线项目风险参考

仅用于 Beagle / 比格，且只在源包出现相应机制时触发。

## 风险矩阵

- 账号与角色：登录态、角色资格、权限差异、切换角色/账号后的状态隔离。
- 场景与关卡：进入条件、初始状态、阶段推进、失败/退出/重进、结算与重置。
- 养成与道具：解锁、升级、消耗、上限、库存、重复操作和重登持久化。
- 任务与活动：接取/完成/领奖、时间边界、刷新、重复领取、阶段切换。
- 社交与组织：成员权限、多人并发、加入/退出后的归属和可见状态。
- 客户端表现：源包明确的 UI、按钮态、提示、红点、动画和适配。

## 组合控制

未知玩法名不自动套用 ROK 或 CoD 机制。只有当前源包能证明共同语义时才使用通用规则。
