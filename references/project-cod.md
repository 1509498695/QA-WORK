# CoD/SAMO 离线项目风险参考

仅用于 CoD、COD、SAMO、万龙觉醒，且只在源包出现相应机制时触发。

## 风险矩阵

- 服务器/地区/平台范围：只验证源包明确存在差异的范围；不默认生成全平台或全地区矩阵。
- 英雄与军团：英雄状态、编队、兵种/单位、行军、驻防、战斗前后状态和资源变化。
- 城市与地图：建筑/城市状态、地图目标、行军冲突、目标消失、跨区域限制。
- 联盟与多人协作：角色权限、成员变化、多人同时操作、共同目标和结算归属。
- 活动/赛季：开放阶段、资格、积分、排行榜、奖励、阶段切换和继承/重置。
- 商业化：商品可见性、价格/币种、购买限制、支付结果、补单/重复操作和到账。
- 动态表现：只有源包明确动画、特效、镜头、音效或动态状态时才触发表现用例。

## SAMO 模块

最终模块名称优先匹配 `samo-project-modules.json` 的已确认条目。无法唯一映射时登记 provisional 模块并转草稿；不得用技术层名称替代业务模块。

## 组合控制

以改变预期结果的差异为组合依据，禁止把服务器、地区、平台、语言、活动阶段、角色和对象做笛卡尔积。
