# QA Skill Hub 公共能力领域语言

本上下文定义 `QA Skill Hub` 中多个业务 Skill 共同使用外部系统能力时的统一语言，避免单仓版本化被误解为公共基建与业务领域合并。

## 工作空间边界

**QA Skill Hub**：
显示名为 `QA Skill Hub`、稳定 ID 为 `qa-skillhub`、以 `D:\project\work` 为唯一 Git 根的项目仓库；它共同版本化业务 Skills 与公共能力，但不合并各自的领域边界。
_Avoid_：QA-WORK、Workspace Capabilities、`D:\project`

**项目仓库根**：
`D:\project\work` 的 Git 根，是本项目源码、架构文档和成员目录的最高边界；共同父目录、远端仓库显示名和本机安装缓存都不定义项目身份。
_Avoid_：`D:\project`、`QA-WORK.git`、用户级 Skills 目录

**能力工作空间**：
由 QA Skill Hub 内多个业务 Skill 与能力 Provider 共同组成、共享契约治理和发现规则的逻辑边界；逻辑成员关系不消除目录、权限和发布边界。
_Avoid_：任意同仓目录、单一 Skill、万能 MCP

**能力平台清单**：
规划用于声明平台稳定身份、公共契约和能力目录的版本化清单。只有 Schema、校验器和真实文件均已实现并验收后，它才构成真源；当前不得假定 `workspace.yaml` 已经存在。
_Avoid_：空壳清单、目录名、安装清单、Provider 私有配置

**成员工作空间清单**：
规划用于声明调用方稳定身份、目标能力平台、任务边界和能力需求的版本化清单；当前实现前不得把目录结构推断成已登记身份。
_Avoid_：空壳清单、调用路径、最近 Workspace、中央物理路径表

**业务 Skills 目录**：
仓库根的 `skills/`，每个直接子目录只持有一个具名业务 Skill 及其私有资源、测试和领域文档。
_Avoid_：Provider Plugin Skills、多个入口共用一个目录、跨目录薄壳

**共享业务包目录**：
规划中的 `packages/`，仅承载已经形成稳定复用合同、独立测试和明确所有权的业务无关或跨 Skill 代码；当前不为未来猜测预建空包。
_Avoid_：私有源码搬家、跨 Skill 相对导入、提前抽象

**本机成员登记**：
仓库外当前用户私有状态中，对能力平台 ID、成员 Workspace ID、已解析清单位置和边界摘要作出的显式绑定。
_Avoid_：跨目录自动扫描、Git 绝对路径、成员自声明即可信

**公共能力契约**：
能力工作空间内业务 Skill 与能力 Provider 共同遵守的稳定语义边界，用于表达能力身份、操作结果和证据含义。
_Avoid_：共享工具函数、Provider 私有协议、业务流程合同

**契约兼容范围**：
业务 Skill 对某项公共能力明确声明并经 Provider 能力声明匹配的一组可接受契约版本。
_Avoid_：仓库当前版本、默认最新版、隐式兼容

**能力 Provider**：
围绕单一外部系统独立拥有身份、权限与受控操作边界的公共能力单元；飞书与 SVN 属于不同的能力 Provider。
_Avoid_：万能 MCP、业务 Skill 内置客户端、跨系统 Provider

**能力平台管理门户**：
管理员统一查看各 Provider 脱敏配置状态并进入其配置台的发现入口；门户不拥有、合并或转存 Provider 配置与凭证。
_Avoid_：万能配置中心、跨 Provider 密钥库、中央 Broker

**Provider Plugin**：
围绕一个外部系统独立安装和发布的 Codex Plugin，包含该 Provider 的 MCP Server 及必要的使用指导 Skills。
_Avoid_：公共 Broker、业务 Skill 合集、多个外部系统共用 Plugin

**Provider 直连消费**：
业务 Skill 按公共契约直接调用目标 Provider MCP 的命名语义工具，公共平台不转发或代执行该调用。
_Avoid_：中央 Broker MCP、Provider 间转发、业务脚本直调远端 API

**受控语义操作**：
由能力 Provider 以用户意图和可验证结果命名、并完整封装外部系统细节的一项稳定操作。
_Avoid_：原始 API 调用、HTTP 透传、任意请求

**能力声明**：
Provider 对其身份、版本、兼容契约、资源类型和受控语义操作作出的可查询声明。
_Avoid_：安装目录、Plugin 清单推测、历史能力

**资源定位符**：
用户提供、用于判断目标通道与资源类型的本地路径、外部资源 URL 或资源标识；它不单独构成读取权限、写入授权或任务身份。
_Avoid_：任务引用、正式目标、授权证明

**任务预检**：
Provider 针对本次任务所需操作、实际工具暴露、配置、执行身份、权限和目标条件给出的只读就绪判断。
_Avoid_：安装成功、全局健康检查、历史授权

**本地构件能力**：
在用户授权的本地边界内读取来源、形成可校验文件并保留回读证据的共享能力；它属于本地运行基础，不是外部系统 Provider。
_Avoid_：Local Provider、文件系统 MCP、飞书离线模式

**业务 Skill**：
面向具体用户目标、编排业务流程并按需消费能力 Provider 的工作流入口；它不拥有外部系统的通用身份和连接职责。
_Avoid_：能力 Provider、公共基础脚本、外部系统客户端

## 身份与授权

**Provider Profile**：
Provider 对一个外部系统用户主体及其长期授权状态的稳定逻辑引用；Profile 本身不包含或暴露凭证，也不限定授权状态必须存放在调用方本机。
_Avoid_：账号密码、Token、最近登录用户

**飞书租户**：
飞书企业自建应用所属并限定用户与资源可见范围的企业身份边界；用户 Profile 和执行客户端都必须归属于一个确定租户。
_Avoid_：Workspace、用户 Profile、飞书群

**租户准入**：
飞书授权控制面对一个已验证飞书租户作出的显式允许登记；OAuth 成功或取得 Token 本身不构成准入。
_Avoid_：自动注册、任意企业可用、用户授权即准入

**任务主体绑定**：
一次任务将确定的 Provider Profile 与外部系统主体固定为后续预检、预览、授权和审计执行身份的关系。
_Avoid_：最近账号、链接推断、运行中自动切换

**本机私有状态**：
位于版本库之外、由当前操作系统用户持有的 Provider 绑定、受管对象登记和恢复状态。
_Avoid_：仓库配置、任务产物、共享状态

**用户委托身份**：
用户明确授权 Provider 代表其访问外部系统资源的身份；对用户内容的读取和写入都归属于该用户。
_Avoid_：当前登录猜测、共享 Token、应用代操作

**Provider 应用身份**：
能力 Provider 用于管理自身内部资源的外部系统应用身份，不得替代用户委托身份访问用户内容。
_Avoid_：默认身份、用户身份回退、万能服务账号

**Provider 专用应用**：
为一个 Provider 独立创建并由其私有管理的外部平台应用；同一 Provider 的业务消费者共享该应用，但不共享用户 Profile。
_Avoid_：复用其他 Provider 应用、每个业务 Skill 一个应用、共享用户 Token

**飞书授权控制面**：
Feishu Provider 集中持有应用身份和用户长期授权、完成 OAuth 生命周期管理的安全边界；它不代理文档或表格业务内容。
_Avoid_：中央 Broker MCP、回调页面、业务数据网关

**控制面部署绑定**：
管理员为一个确定的飞书授权控制面实例一次性建立的 Provider 专用应用与准入租户绑定；完成后，日常启动和业务用户授权不再要求输入应用配置。
_Avoid_：源码写死、每次启动输入、业务用户配置

**控制面部署解绑**：
管理员明确移除一个控制面实例完整部署绑定的本机管理操作；解绑后的实例不再具备 Provider 应用与准入租户身份，必须重新建立绑定才能提供授权能力。部署解绑本身不表示外部平台应用、密钥或用户授权已经撤销。
_Avoid_：删除单个必填字段、保留半配置、自动回退租户发现、远端撤销

**控制面配置台**：
仅供管理员建立、检查和维护控制面部署绑定的管理入口；普通 OAuth 用户与业务 Skill 不具备访问或修改配置的资格。
_Avoid_：用户设置页、OAuth 授权页、Skill 配置面板

**控制面配置会话**：
管理员显式开启、用于单次建立或变更控制面部署绑定的短时管理授权；保存成功、主动取消或超时都会使其失效。
_Avoid_：常驻写入口、localhost 即管理员、跨次复用配置权限

**Provider 执行客户端**：
经飞书授权控制面登记和认证、取得指定 Profile 短期访问能力并直接执行飞书语义操作的 Provider 运行实例。
_Avoid_：业务 Skill、共享账号、长期凭证副本

**执行客户端身份**：
由单个 Provider 安装实例持有的独立 X.509 证书及其稳定 `client_ref`，用于通过 mTLS 向授权控制面证明本机私钥持有关系。
_Avoid_：共享 API Key、飞书用户 Token、客户端自报 ID

**本机开发客户端身份**：
仅在 `local-dev-v0` 中标识同机唯一 Provider 执行实例的临时身份边界；它不得被视为正式执行客户端身份或扩展为多人共享凭证。
_Avoid_：生产客户端身份、mTLS 等价物、跨设备共享密钥

**客户端一次性登记**：
管理员批准客户端公钥并将其绑定到确定 `tenant_ref`、`client_ref` 和生命周期状态的单次引导过程；登记凭据成功或过期后失效。
_Avoid_：长期注册码、自动信任新设备、复制既有证书

**客户端 Profile 绑定**：
由已验证飞书用户确认、允许一个确定执行客户端在获批语义能力范围内为其确定 Provider Profile 申请短期访问令牌租约的可撤销关系。
_Avoid_：管理员代用户授权、同租户自动共享、业务 Skill 自报 Profile

**绑定语义能力集**：
客户端 Profile 绑定中由用户明确批准的稳定 Provider 语义能力 ID 集合，是该客户端使用该 Profile 的授权上限。
_Avoid_：全部当前 Scope、读写布尔值、Provider 升级自动扩权

**绑定请求**：
执行客户端通过 mTLS 发起、由目标 Profile 用户在授权控制面浏览器页面单次批准或拒绝的短时不可变请求。
_Avoid_：对话确认布尔值、OAuth 成功即绑定、浏览器回传 Token

**短期访问令牌租约**：
飞书授权控制面即时向确定执行客户端交付的、绑定任务、Profile、语义能力和 Scope、最长十分钟且可完整重检续租的临时访问能力；客户端只在该任务的进程内存中持有。
_Avoid_：Refresh Token、跨任务 Token 会话、正式写入授权

**增量能力授权**：
用户只为当前 Profile 本次实际需要的外部系统语义操作补充缺失 Scope 的授权过程；它扩展 Profile 的可用能力，但不授权任何一次正式写入。
_Avoid_：一次性全量授权、默认 Scope、正式写入授权

**普通撤销**：
停用确定执行客户端或客户端 Profile 绑定并立即阻止其新租约与续租、但不扩大到整个 Profile 的日常处置。
_Avoid_：删除全部用户凭证、继续续租、紧急隔离

**紧急 Profile 隔离**：
怀疑凭证泄漏时阻止一个 Profile 的全部新租约、销毁控制面长期凭证并要求用户重新 OAuth 的跨客户端处置。
_Avoid_：仅等待租约到期、声称本地删除等于远端失效、静默恢复

## 任务内容与状态

**任务引用**：
由本地构件能力签发、绑定调用方 Workspace、任务身份、合同版本和已校验物理边界的逻辑 `task_ref`；它不是文件路径，也不单独构成读写授权。
_Avoid_：绝对路径、目录别名、Provider 自建任务 ID

**任务内容快照**：
由业务 Skill 持有在任务隔离暂存区内，对一次来源读取形成的完整、不可变且可校验的正文、结构、图片、附件及规范化证据集合。
_Avoid_：Provider 正文缓存、跨任务共享副本、实时链接

**任务清理确认**：
用户查看包含确定任务边界、绝对路径、数量、大小和哈希的清理计划后，对该计划作出的单次确认；计划内容变化会使确认失效。
_Avoid_：任务结束即删除、定时自动删除、宽泛目录许可

**恢复胶囊**：
Provider 仅在远端写入结果不明确时，为同一次操作加密保存的最小对账状态；它与任务、目标和操作绑定，不得被检索或复用为业务内容缓存。
_Avoid_：任务快照、常驻备份、跨任务缓存

**恢复墓碑**：
恢复胶囊解决或经用户明确放弃后保留的不含业务正文的最小状态记录，用于阻止同一授权、操作或目标被自动盲目重试。
_Avoid_：恢复胶囊、可重试标记、完整审计包

## 远端资源与交付

**交付意向**：
用户在预览形成前表达的期望交付通道或目标，用于准备交付方案，但不授权正式写入。
_Avoid_：默认通道、历史选择、正式确认

**正式写入授权**：
用户查看预览后对确定的通道、目标、操作、内容和执行身份作出的单次确认；任一绑定内容变化都会使其失效。
_Avoid_：布尔确认、宽泛许可、沿用上次确认

**受管交付对象**：
Provider 为一次经授权的正式交付新建并登记、且能证明当前状态和后续修订归属的远端对象。
_Avoid_：任意既有对象、来源对象、只读模板、临时副本

**飞书来源资源**：
用户明确提供、可被完整固化为正文、结构、表格、图片、附件和远端定位证据的飞书 Docx、Wiki 或 Sheets 内容。
_Avoid_：飞书链接本身、多维表格、群消息、项目数据

**飞书交付资源**：
由飞书 Provider 新建并作为受管交付对象登记的 Docx 或 Sheets。
_Avoid_：既有 Wiki 节点、多维表格、任意 Drive 文件

**可能已修改**：
远端写入已经开始但最终效果无法被当前证据判定的交付状态；该状态会阻止盲目重试和同目标新写入。
_Avoid_：写入失败、可以重试、未发生修改

**恢复对账**：
依据原写入检查点和远端回读，判定同一次授权操作已完成、未发生或仍无法确认的只读恢复过程。
_Avoid_：重新写入、重新新建、默认回滚

**语义回读合同**：
针对一种交付资源定义其必须从实际目标重新读取并精确匹配的业务结构、内容与格式语义。
_Avoid_：接口成功、字节相等、抽样检查

**已验证交付**：
正式写入完成且实际目标通过全部适用语义回读合同的交付状态。
_Avoid_：对象已创建、请求成功、部分验证、预览完成
