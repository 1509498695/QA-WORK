# 公共能力领域语言

本上下文只定义业务 Skill 与外部系统 Provider 之间共享的 Provider 中立语言。

## 参与者

**业务 Skill**：
面向确定用户目标、组织业务步骤并按需消费公共能力的工作流入口；它拥有业务规则和交付判断，不拥有外部系统的通用连接与身份。
_Avoid_：能力 Provider、通用外部系统客户端、工具合集

**能力 Provider**：
围绕一个外部系统独立拥有资源语义、身份、权限和操作边界的能力单元。
_Avoid_：万能 Provider、业务 Skill 内置连接器、跨系统共享身份

**Provider Plugin**：
把一个能力 Provider 的公开工具与使用指导作为同一可发现单元交付给执行环境的包装边界。
_Avoid_：业务 Skill 合集、公共 Broker、多个 Provider 的共享凭证容器

**普通成员**：
通过业务 Skill 使用平台已开放能力、且只属于当前控制面内一个团队的人；其业务入口不要求理解或维护 Provider 部署配置。
_Avoid_：访客、平台管理员、由首次选择永久固化的角色

**团队管理员**：
在确定团队边界内管理成员、邀请和团队展示资料的人；一个团队可以有多名管理员且必须始终至少保留一名，创建者只是首位管理员。该资格不能修改控制面、Provider Secret、平台权限或其他团队。
_Avoid_：平台管理员、永久团队所有者、共享团队账号

**平台管理员**：
维护中央控制面、Provider 部署绑定和平台级管理恢复的人；平台管理员可以有多名，不设置平台所有者。资格来自 Bootstrap 或现有平台管理员的受控授予，不来自用户自报、团队创建或普通 OAuth。
_Avoid_：平台所有者、共享管理员密码、首位网页访问者、团队管理员自动升级

**平台身份**：
中央控制面在飞书 OAuth 和租户准入验证通过后，为稳定外部用户主体幂等建立的内部引用；它不要求平台用户名或密码，也不单独授予团队成员资格或任何管理权。
_Avoid_：显示名称、邮箱或手机号主键、团队角色、Provider Token

**平台身份票据**：
Feishu Provider 在真实 OAuth、租户准入和用户身份回读完成后签发的短时、单次、绑定控制面 PKCE 登录事务的私有交付能力；它只携带稳定主体与展示属性，由控制面后台兑换，永不携带 Access Token、Refresh Token 或 App Secret。
_Avoid_：浏览器自报身份、长期 bearer token、跨 Provider 通用身份协议、把 OAuth Token 复制进平台库

**身份展示**：
围绕同一不可变平台身份组合飞书认证姓名、用户可编辑的平台显示名称、团队管理员可编辑的团队备注和 `user_ref` 短标识；展示字段可以变化或重复，管理与审计场景不得隐藏认证来源和稳定主体。
_Avoid_：以昵称授权、强制显示名称全局唯一、改名创建新身份

**客户端控制面绑定**：
一个 Provider 执行客户端与一个确定中央授权控制面实例之间的受控关系；客户端只使用该控制面为当前平台身份登记的唯一有效团队，不同时连接或自动切换其他控制面。替换绑定必须先完整验证新控制面，再原子切换并撤销旧客户端，且不得删除旧平台身份、审计或未完成恢复证据。
_Avoid_：多控制面环境切换器、按任务猜测中央服务、静默覆盖现有绑定、切换即删除旧身份

**团队成员资格**：
平台身份在一个确定中央控制面内与一个团队之间的唯一有效关系；加入另一团队是原子换队，成功后结束旧关系但保留其历史与审计，不形成多团队并存。
_Avoid_：当前团队选择器、先退出后尝试加入、删除旧成员历史、跨控制面全局成员关系

**团队邀请**：
由团队管理员签发、绑定确定团队和准入租户、可到期并撤销的入队意向；它允许已验证用户直接建立或原子替换团队成员资格，但不替代飞书 OAuth，也不携带任何 Provider 凭证。
_Avoid_：公开永久入队地址、重复审批申请、邀请链接自报身份、链接内嵌 Token

**团队身份**：
中央控制面为一个团队建立的稳定 `team_ref`；活动团队名称在同一控制面内规范化唯一，普通展示资料可以受控修改，但重命名不创建新团队，也不切断成员、受管对象、操作历史或审计链。
_Avoid_：以团队名称作为身份、重命名即重建、借资料修改更换控制面或租户

**使用路径**：
产品根据当前用户目标和可检测就绪状态提供的引导分支；它只调整界面与说明，不授予权限或替代任何授权证明。
_Avoid_：用户角色、权限等级、授权身份

**公共能力契约**：
业务 Skill 与能力 Provider 共同遵守的稳定语义，用于表达操作状态、能力声明、证据和安全错误；它不枚举任何外部系统的私有资源类型。
_Avoid_：Provider 私有协议、共享工具函数、远端 API Schema

**Provider 私有协议**：
同一 Provider 内部部署单元之间交换身份或授权信息的合同；它不对业务 Skill 构成公共能力。
_Avoid_：公共能力契约、业务流程合同、跨 Provider 协议

## 操作与声明

**本机初始化入口**：
由用户从已检出的 QA Skill Hub 仓库主动运行、幂等协调当前用户范围内 Provider Plugin、业务 Skill 发现入口、必要依赖与首次只读就绪验证的单一入口；它只使用仓库已有标准清单和规范源码，不主动更新 Git，不覆盖同名非受管内容，也不替代 OAuth、团队关系或任何管理授权。
_Avoid_：分散安装清单、静默追逐任意最新版本、管理员权限安装器、安装即授权

**受控语义操作**：
以用户意图和可验证结果命名、由 Provider 完整封装外部系统细节的一项稳定操作。
_Avoid_：原始 HTTP 请求、任意 API 透传、远端 SDK 方法名

**能力声明**：
Provider 对自身身份、版本、兼容契约、资源类别和受控语义操作作出的可查询声明。
_Avoid_：安装目录、历史能力、根据工具名称猜测

**资源定位符**：
用户提供、由目标 Provider 判断资源类型和规范身份的值；它不单独构成读取权限、写入授权或任务身份。
_Avoid_：授权证明、任务引用、操作结果

**任务引用**：
调用方为一次逻辑任务提供的非秘密稳定引用，用于关联操作与证据；它不是路径、凭证或授权决定。
_Avoid_：访问令牌、目标定位符、工作目录

**任务预检**：
Provider 针对本次所需能力、配置、执行身份和权限给出的只读就绪判断。
_Avoid_：安装成功、历史授权、全局健康检查

**写入预览**：
Provider 对一次拟执行变更的目标、动作、执行主体、目标当前状态和内容摘要所作的不可变说明；它本身不产生外部副作用。
_Avoid_：写入请求、内容草稿、确认布尔值

**正式写入授权**：
用户针对一份确定写入预览授予的短期、单次变更许可；目标、主体、动作、内容或远端前置状态变化后，该授权立即失效。
_Avoid_：OAuth Scope、Provider Profile、通道意向

**Provider 直连消费**：
业务 Skill 直接调用目标 Provider 的公开语义操作，公共契约层不转发、代执行或持有 Provider 凭证。
_Avoid_：中央 Broker、Provider 间转发、业务脚本直调远端 API

## 结果与证据

**操作状态**：
Provider 对一次操作语义结果的结构化结论；成功与读取不完整必须是不同状态。
_Avoid_：HTTP 状态码、日志级别、异常文本

**操作证据**：
证明一次读取或变更所观察内容、修订、完整性和警告的结构化记录。
_Avoid_：运行日志、Provider 缓存、未经定位的说明

**语义回读**：
正式变更后按资源类型重新读取实际对象，并将关键内容与结构同已授权预期逐项比较的验证行为。
_Avoid_：成功响应、内存对象比较、抽样检查

**恢复对账**：
远端变更结果无法确定时，围绕原任务、授权和目标执行的只读状态核验，用于判断原操作已完成、尚未发生或仍需人工恢复。
_Avoid_：自动重试、替代写入、默认回滚

**前向恢复**：
部分远端步骤已成功后，基于原目标、原规范摘要和已验证检查点继续完成或确认同一次操作；恢复过程不删除已创建资源，也不清空已接管资源。
_Avoid_：自动回滚、重新执行整套写入、改写其他目标

**读取完整性**：
Provider 对目标范围是否被完整枚举、读取和验证的判断；存在未解析内容或安全截断时不得声明完整。
_Avoid_：请求成功、读取到部分内容、抽样无异常

**安全错误**：
对调用方稳定公开、不会夹带凭证、远端原始正文或不受信任恢复地址的失败语义。
_Avoid_：原始异常、远端响应透传、Secret 脱敏后回传

**本地构件能力**：
在用户授权的本地边界内读取来源、形成文件并保留回读证据的能力；它不是外部系统 Provider。
_Avoid_：Local Provider、离线外部系统、文件系统万能 MCP
