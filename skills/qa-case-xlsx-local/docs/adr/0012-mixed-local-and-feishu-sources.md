# 统一入口允许混合本地与飞书来源

`qa-case-xlsx-unified` 允许同一个任务的策划案源包同时包含本地来源和飞书来源，并为每一份来源保留独立、稳定的身份与来源链。飞书路径只有在飞书 Provider 已完整固化正文、结构、表格、图片、附件、远端定位及完整性状态后才能成为来源证据；路径本身不能代替内容快照。正式生成要求用户声明的每一份来源均完成读取、证据审查与冲突处理；任一来源因权限、读取不完整或事实冲突而未闭环时，任务只能保持待确认或草稿状态，不得产生正式交付。`qa-case-xlsx-local` 继续只接受本地来源，不继承混合来源能力。

## Considered Options

- 每个任务只允许一种来源通道：拒绝，因为用户必须人为拆分同一需求的证据，且跨来源关系无法在同一审计边界内闭环。
- 将飞书路径当作普通本地文件路径：拒绝，因为这会丢失远端定位、修订、权限与读取完整性证据。
- 某一来源失败时忽略该来源继续正式生成：拒绝，因为输出会在用户声明的证据范围不完整时伪装成正式结果。
