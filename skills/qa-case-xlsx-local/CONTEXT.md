# qa-case-xlsx-local 领域语言

本上下文只定义从本地策划案生成可审计 Excel 测试用例的业务语言。

## 系统边界

**独立用例系统**：
以 `qa-case-xlsx-local` 为唯一入口、只读取本地来源并交付本地工作簿的测试用例系统。
_Avoid_：QAWORK 子流程、飞书用例生成、在线交付入口

**纯本地边界**：
来源、证据、生成、校验和交付全部在用户明确授权的本地范围内完成，不跟随材料中的外部链接。
_Avoid_：离线优先、网络降级、可选在线来源

**运行批次**：
一次来源读取、用例生成、审计和工作簿交付共享的稳定执行边界。
_Avoid_：进程、临时目录、历史任务

## 来源与事实

**本地来源**：
用户本次上传或明确指定的 DOCX、PDF、XLSX、Markdown、TXT 或图片文件。
_Avoid_：外部链接、历史材料、自动扫描文件

**来源身份**：
一份本地来源在源包和后续证据链中保持不变的归属标识。
_Avoid_：展示标题、临时渲染路径、文件内容哈希

**策划案源包**：
同一运行批次中全部本地来源的集合；每份来源保持独立身份，不因名称或内容相似而合并。
_Avoid_：输入文件夹、拼接文档、参考资料集合

**来源证据**：
能够回溯到确定来源及其段落、页面、工作表、单元格或图片位置的业务事实依据。
_Avoid_：模型常识、规则推断、未复核截图

**视觉证据**：
必须通过实际渲染或查看才能确认的页面、工作表、图片或嵌入对象证据。
_Avoid_：文本提取结果、文件存在、缩略图猜测

**来源事实**：
由来源证据直接支持、供用例生成消费的最小业务陈述。
_Avoid_：测试建议、历史玩法、未证实配置值

**来源冲突**：
不同来源对同一业务事实给出互斥结论的状态；解决前相关事实保持待确认。
_Avoid_：最新文件覆盖、按顺序取值、模型裁决

**旧玩法基线缺口**：
来源声明沿用或复用旧玩法，却没有提供可验证旧行为的证据缺口。
_Avoid_：默认继承、历史常识、自动补齐回归项

## 用例生成

**生成蓝图**：
把已确认事实组织为业务目标、角色、入口、状态、数据边界、异常恢复和回归关系的中间语义结构。
_Avoid_：最终用例、思维过程、需求摘要

**完整性矩阵**：
逐项说明规定测试维度已覆盖、不适用或仍待确认的审计结构。
_Avoid_：用例数量目标、覆盖率百分比、测试结果统计

**待确认边界清单**：
从来源缺口、冲突和未定业务边界中提炼的结构化问题，每项包含建议口径与证据定位。
_Avoid_：执行用例、Excel Sheet、口头备注

**基础用例**：
仅由已确认来源事实自然展开、尚未应用个人规则的业务测试场景。
_Avoid_：最终用例、示例用例、规则生成用例

**候选用例**：
基础用例经过适用规则评估、拆分或补充后形成，等待去重和最终表达的场景。
_Avoid_：正式交付用例、规则本身、待确认事实

**最终用例**：
通过事实、规则、去重、字段职责和可追溯性门禁后写入工作簿的测试场景。
_Avoid_：候选用例、草稿状态、工作簿行号

**语义签名**：
根据业务对象、前置状态、触发动作、目标状态和核心预期计算的稳定去重身份。
_Avoid_：用例编号、文本哈希、Excel 行号

**正式规则包**：
经确认并受版本与哈希约束的个人测试规则集合；运行批次不得从历史材料自动改写它。
_Avoid_：经验库、候选规则、模型偏好

**规则评估**：
针对每条适用规则记录其是否适用、证据、原因和产生的候选用例。
_Avoid_：规则命中计数、隐式提示词、无证据补充

**用例映射账本**：
记录基础用例、候选用例和最终用例之间保留、拆分、合并或改写关系的审计结构。
_Avoid_：执行日志、用例目录、结果统计

## 本地交付

**个人用例版式**：
固定 A:J 字段职责、蓝色双层标题和连续模块分组的本地工作簿展示合同。
_Avoid_：在线表格、Excel Table 主题、临时排版

**连续模块分组**：
按用例业务顺序形成的相邻同名模块组；二级模块不跨一级模块合并。
_Avoid_：全局同名合并、排序后重组、跨一级模块合并

**待确认草稿**：
来源不完整、证据冲突或关键事实未确认时允许形成的非正式工作簿。
_Avoid_：正式交付物、用例完成、无证据占位

**正式本地交付物**：
全部正式门禁通过且待确认项为零的本地用例工作簿。
_Avoid_：待确认草稿、审计包、预览图片

**工作簿回读**：
从实际生成文件重新读取字段、行数、语义签名和结构，以证明写入结果与最终用例一致。
_Avoid_：内存对象比对、保存成功、文件存在

**视觉复核**：
查看实际渲染工作簿，确认标题、列宽、行高、换行、分组和可读性的交付门禁。
_Avoid_：程序结构检查、截图已生成、抽样文件属性

**审计包**：
记录来源、事实、生成决策、规则评估、用例映射、校验和工作簿证据的可复核产物集合。
_Avoid_：运行日志、中间缓存、工作簿替代物

**已交付**：
正式或草稿工作簿已通过对应门禁并交给用户，文件名、内容、回读和复核状态一致。
_Avoid_：脚本运行成功、文件已创建、预览已生成
