# qa-case-xlsx-local 领域语言

qa-case-xlsx-local 是一个独立的测试用例生成与交付系统。本文件只定义系统内的统一术语，不记录实现状态或实施步骤。

## 系统边界

**独立用例系统**：
以 `qa-case-xlsx-local` 为唯一用户入口、只处理本地来源并交付本地工作簿的测试用例系统。它可以使用 Codex 基础运行时，但不消费 QAWORK、飞书或其他在线系统的代码、命令、身份、目录、模板绑定或私有状态。
_Avoid_：修改版 qa-case-xlsx、QAWORK 子模块、qa-case 附属流程

**QAWORK 原版**：
以 `qa-case-xlsx` 为用户入口、属于 QAWORK 语境的既有个人风格在线用例 Skill；它与独立用例系统是两个不同身份，不能互相替代。
_Avoid_：独立本地版、qa-case-xlsx-local、独立用例系统旧版

**纯本地兼容入口**：
保持 `qa-case-xlsx-local` 既有名称与纯本地权限边界的业务 Skill 入口；新增统一入口后，它仍不读取或写入飞书。
_Avoid_：统一入口别名、飞书降级入口、旧入口

**统一用例入口**：
以 `qa-case-xlsx-unified` 为名称，与纯本地兼容入口和 QAWORK 原版并存、统一承接本地或飞书来源及本地或飞书交付选择的新业务 Skill 身份。
_Avoid_：qa-case-xlsx-local 新版、QAWORK 原版替代品、自动转发入口

**系统工作区**：
独立用例系统唯一拥有的运行与证据边界，用于区分其来源、任务、授权状态和交付记录。
_Avoid_：QAWORK 工作区、临时目录

**任务暂存区**：
系统工作区内保存来源快照、审计证据和交付预览的隔离区域；其中的产物用于复核与恢复，但不构成正式交付。
_Avoid_：最终输出目录、正式交付物、用户目标位置

**任务引用**：
在同一业务任务内稳定关联来源读取、回执、快照和审计记录的非秘密逻辑标识；它不表示物理目录，也不构成身份、权限或正式写入授权。
_Avoid_：任务路径、访问令牌、授权码

**任务清单**：
记录业务任务身份、所有权、生命周期及来源构件引用的权威索引，是任务恢复和同对象回读的入口。
_Avoid_：运行日志、配置文件、交付清单

**QAWORK 独立性**：
独立用例系统的输入、处理、授权、交付和恢复均不需要 QAWORK 存在或可用。
_Avoid_：复用 QAWORK、从 QAWORK 启动

**工作空间公共能力层**：
在当前工作空间内由多个业务 Skill 共同消费、且不归属于任何单一业务 Skill 的可扩展能力边界；飞书读写、SVN 读取等外部系统能力属于这一层。
_Avoid_：QAWORK 公共能力、单一业务 Skill 私有能力、万能 Skill

**公共能力契约**：
业务 Skill 与能力 Provider 共同遵守的稳定语义边界，用于统一表达能力身份、操作结果和证据含义，不承载外部系统专属规则。
_Avoid_：共享工具函数、Provider 私有协议、业务流程合同

**能力 Provider**：
围绕单一外部系统独立拥有身份、权限与受控操作边界的公共能力单元；飞书与 SVN 属于不同的能力 Provider。
_Avoid_：万能 MCP、业务 Skill 内置客户端、跨系统 Provider

**业务 Skill**：
面向具体用户目标、编排本地流程并按需消费能力 Provider 的工作流入口；它不拥有外部系统的通用身份和连接职责。
_Avoid_：能力 Provider、公共基础脚本、外部系统客户端

**纯本地边界**：
独立用例系统的来源、证据、生成、校验与交付都在本地完成，不读取或写入飞书，也不访问任务材料中的外部链接。
_Avoid_：离线优先、飞书可选、网络降级

## 来源与证据

**策划案来源**：
用户本次明确提供、且能被系统完整读取和定位的一份需求材料。
_Avoid_：参考资料、外链

**本地来源**：
由用户上传或明确指定的本地 DOCX、PDF、XLSX、Markdown、TXT 或图片文件。
_Avoid_：离线文档

**飞书来源**：
由用户明确提供的飞书 Docx、Wiki 或 Sheets 路径，经飞书 Provider 完整固化正文、结构、表格、图片、附件、远端定位与完整性状态后形成的来源；路径本身不构成来源证据。
_Avoid_：飞书链接、在线参考资料、未固化远端内容

**来源识别**：
系统依据用户明确提供的本地文件或飞书路径判定相应来源通道，不要求用户另行选择输入模式；无法可靠识别的对象不作为来源。
_Avoid_：手动输入模式、模型猜测来源、跟随未提供的外链

**来源身份**：
一份策划案来源在源包及后续证据链中保持不变的归属标识，同时保留其本地或飞书来源类型与原始定位。
_Avoid_：展示名称、临时下载路径、统一文件路径

**策划案源包**：
同一次生成任务中全部本地来源与飞书来源的集合；两类来源可以混合，各来源保持独立身份，不因标题或内容相似而合并。
_Avoid_：合并文档、输入文件夹

**来源回执**：
系统对一次来源读取所保存的不可变、经安全筛选的审计记录，用于证明读取主体、来源身份、修订、内容哈希、完整性和警告，不作为下游业务内容语义。
_Avoid_：原始日志、Provider 缓存、规范化来源快照

**规范化来源快照**：
由来源回执所证明、以 Provider 中立语义固定的一版来源内容与证据结构；它引用来源回执及内容资产，是后续事实提取和用例生成所消费的来源表示。
_Avoid_：Provider 原始结果、临时下载文件、来源回执

**来源证据**：
能够回溯到具体来源及其段落、页面、表格、单元格、文档块或图片位置的业务事实依据。
_Avoid_：模型判断、常识补充

**源包冲突**：
不同来源对同一业务事实给出互斥结论的状态；冲突解决前相关内容保持待确认。
_Avoid_：版本覆盖、最新文档优先

**旧玩法基线缺口**：
来源只声明沿用或复用旧玩法，却没有提供可验证旧行为的证据缺口。
_Avoid_：默认继承、历史常识

## 用例与审计

**完整用例集**：
未预设条数、由已确认事实与适用风险维度自然展开，并能逐条回溯来源的用例集合。
_Avoid_：固定数量用例、示例用例

**个人用例版式**：
以用户确认的蓝色双层标题用例表为唯一默认展示合同，只展示 DRI、本地来源、用例总数、结果统计和模块层级，不承载审计元数据，也不叠加 Excel Table 主题；正式与草稿不切换版式。
_Avoid_：绿色版式、筛选表主题、可选主题、临时排版

**连续模块分组**：
按用例业务顺序形成的相邻同名模块组；一级模块独立分组，二级模块只在同一一级模块内分组，不跨越其他模块合并。
_Avoid_：全局同名合并、跨一级模块合并

**待确认草稿**：
来源不完整、证据冲突或关键事实未确认时允许形成的非正式用例产物。
_Avoid_：正式用例、交付完成

**待确认边界清单**：
从来源缺口、来源冲突和未定实现边界中提炼的结构化决策问题，每项包含建议口径和可回查证据；它独立于执行用例并随草稿交付给用户确认。
_Avoid_：待确认用例、Excel 边界 Sheet、待确认数量

**审计包**：
记录来源、事实、生成决策、规则应用、映射、校验和工作簿回读证据的可复核产物集合。
_Avoid_：日志目录、中间文件

**正式规则包**：
经确认并受版本与哈希约束的个人测试规则集合；运行过程不得自动从历史材料改写它。
_Avoid_：经验库、候选规则

## 本地交付

**交付通道选择**：
用户在本次任务的交付写入开始前，对本地或飞书通道作出的明确选择；来源类型和历史选择都不构成本次交付授权。
_Avoid_：默认本地、跟随来源、沿用上次选择

**正式交付写入**：
向用户本次确认的本地目标位置或飞书目标对象写入交付物的行为；任务暂存区内的证据与预览写入不属于正式交付写入。
_Avoid_：暂存写入、预览生成、来源快照

**本地用例工作簿**：
按个人用例版式生成、通过 A:J 内容与工作簿结构回读的 `.xlsx` 文件。
_Avoid_：在线表格、恢复包、预览文件

**正式本地交付物**：
全部正式门禁通过且没有待确认项的本地用例工作簿；审计包用于复核，但不替代根目录工作簿。
_Avoid_：待确认草稿、审计包、生成成功

**已交付**：
正式或草稿本地用例工作簿已经通过对应门禁并交给用户，文件名、内容和回读状态一致。
_Avoid_：脚本运行成功、文件已创建、预览已生成
