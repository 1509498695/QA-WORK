# 限定首版飞书资源范围

飞书 Provider 首版读取 Docx、Wiki 和 Sheets，并将其中可访问的图片与附件纳入完整来源快照；首版写入仅新建或修订受管 Docx 与受管 Sheets。Wiki 只承担路径解析和内容入口，不原位修改既有 Wiki 节点；Bitable、多维表格、群消息、飞书项目及任意 Drive 文件管理均不属于首版公共能力，后续只能以独立语义、权限和回读合同扩展。

## Considered Options

- 首版覆盖全部飞书产品：拒绝，因为不同资源的权限、分页、结构、写入和回读语义差异过大，无法形成可信的统一完成状态。
- 首版只支持 Sheets：拒绝，因为策划案常以 Docx 或 Wiki 提供，未来报告类业务 Skill 也需要受管 Docx 交付。
- 将 Wiki 当作可直接覆盖的文档：拒绝，因为 Wiki 路径、节点和实际内容资源不是同一对象，且既有节点已确定默认只读。

## Consequences

- 资源解析必须返回真实资源类型；不支持的资源返回明确的 `unsupported_resource`，不得降级成纯文本链接。
- 图片或附件无法完整获取时，飞书来源快照不得标记为完整。
