# 指定飞书模板作为复制母版

用户本轮提供的既有飞书用例模板是首次在线交付的唯一复制母版，并由独立用例系统在自身 Provider 边界内以逻辑名 `qa-case-template-sheet` 登记；模板的真实链接和标识只进入 Provider 私有绑定，不写入仓库。模板保持只读且不被原位修改，每次交付都复制出新的 AI-owned 用例表。系统冻结用户已接受的模板合同，每次复制前都重新校验；模板后续发生不兼容变化时视为模板漂移并停止交付，不自动跟随。这个选择保留了用户认可的版式与表格语义，同时拒绝复用 QAWORK 的模板绑定，以维持系统身份、授权与恢复状态的独立性。

## Consequences

- 独立工作区完成初始化并验证模板类型、结构、权限与复制策略之前，不得宣称该模板可用于生成。
- 模板校验或复制准备状态失败时必须零写入停止，不得静默切换成本地模板、空白表或其他在线表。
- 每次复制都必须对照已接受版本重新验证模板合同；检测到模板漂移时不得复制。
- 只有重新核验变化、更新模板合同版本并取得用户明确确认后，系统才能接受新的模板状态。
- 仓库只引用稳定逻辑名；模板真实链接、标识和绑定状态由飞书 Provider 私有保存。
