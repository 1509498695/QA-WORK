# 飞书交付权威性

系统自有飞书用例表是正式交付物，本地 `.xlsx` 与审计包是每次线上写入前必须生成并校验通过的证据和恢复副本；只有本地门禁、飞书写入及线上精确回读全部通过，任务才能进入“已交付”。这一区分避免把本地生成成功、对象创建成功或请求返回成功误报为可供用户使用的线上交付。

## Consequences

- 本地恢复包失败时不得尝试飞书写入。
- 本地恢复包成功但飞书授权、写入或回读失败时，可以保留本地产物供恢复，但任务仍未交付。
- 飞书写入结果不明时必须沿用原操作状态人工核对，不得通过新建另一份表格伪造成功。
