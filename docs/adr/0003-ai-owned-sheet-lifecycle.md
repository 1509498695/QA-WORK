# AI-owned 飞书用例表生命周期

每次首次飞书交付都从已登记且验证通过的指定用例模板复制，新建一份由独立用例系统拥有并登记的 AI-owned 用例表，不直接覆盖模板、用户表格或其他系统已有的表格；后续修订只允许作用于同一系统自有用例表，并绑定当前内容状态、写入预览与用户确认以及写后语义回读。这个边界以可证明的对象所有权和恢复能力换取了较少的任意写入自由，避免外部表格被误改或在失败后无法判断实际状态。

## Consequences

- 任意既有飞书表格不作为写入目标，即使当前账号具有编辑权限。
- 指定用例模板始终只读且仅供复制；模板不可验证或不可复制时首次交付必须零写入停止，不得改用空白表或本地模板降级。
- 首次交付与后续修订使用不同操作语义，不得把重新新建伪装成修订恢复。
- 无法证明对象由本系统创建并登记时，修订必须零写入失败关闭。
