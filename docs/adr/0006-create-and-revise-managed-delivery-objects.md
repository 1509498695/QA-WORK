# 首次新建并仅修订受管交付对象

用户提供的既有飞书 Docx、Wiki、Sheets 和模板默认只读；首次正式飞书交付在用户确认的容器中创建或从只读模板复制出新的受管交付对象，并登记对象标识、用户主体、创建检查点和初始内容状态。后续修订只允许作用于同一登记对象，且必须绑定写前快照或内容哈希、写入预览、用户确认、幂等检查点及写后精确回读；初版不提供任意既有飞书对象的原位修改能力。

## Considered Options

- 在用户有编辑权限时直接修改任意既有对象：拒绝，因为权限不等于本次业务授权，也无法证明对象当前内容由哪个流程负责。
- 每次修订都新建一个对象：拒绝，因为交付历史会分叉，失败恢复和用户引用都无法保持稳定。
- 将用户提供的来源对象同时作为交付目标：拒绝，因为读取来源的授权不能推导出覆盖原文的授权。

## Consequences

- 若现有对象需要作为版式母版，只能读取并复制；母版本身不得被修改。
- 写入结果不明时必须沿用原检查点查询或回读同一对象，不得静默新建另一个对象伪装成功。
- 将来若支持修改任意既有对象，必须新增独立高风险语义、并发前置条件和单独 ADR，不能放宽本能力的含义。
