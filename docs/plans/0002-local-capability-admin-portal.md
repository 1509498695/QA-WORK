# 本机公共能力管理门户与 Feishu 配置台

## 目标

在不复用 `lg-feishu`、不暴露明文凭证、也不把不同 Provider 配置合并存储的前提下，为本机管理员提供统一公共能力管理门户。首版只接入 Feishu Provider，完成部署绑定的创建、修改、删除、回读与后续零输入启动。

## 实现状态

首版已于 2026-08-20 完成：DPAPI 本机绑定、十分钟单次配置会话、Feishu 配置页、脱敏预览、原子保存与回读、二次确认删除、零输入 OAuth 启动器均已落地。2026-08-24 的 Docx Provider 纵切进一步取消了 `tenant_key` 手工输入，改为使用应用凭证从飞书租户信息接口自动回读并由管理员确认。

## 已确认边界

- 门户统一展示 Provider 脱敏状态和入口；配置字段、校验、持久化与凭证仍由各 Provider 独立拥有。
- 配置网页只在管理员显式启动的单次短时会话中可写，正常 OAuth 服务与配置模式互斥。
- 首版 Feishu 可编辑字段只有 App ID 和 App Secret；准入 `tenant_key` 由飞书自动回读，回调地址、Scope、监听地址和端口只读。
- 创建和修改执行“填写、脱敏预览、确认、原子写入、回读”；删除需要精确短语并真实移除本机绑定。
- 本机删除不代表飞书远端应用、App Secret 或用户授权已经撤销。

## 本机状态合同

- 默认路径：`%LOCALAPPDATA%\WorkspaceCapabilities\providers\feishu\binding.json`。
- 单个版本化 JSON 绑定文件保存非敏感字段和 DPAPI 当前用户保护的 App Secret 密文；整个文件按当前 Windows 用户边界管理。
- 创建和修改先写同目录临时文件、完整回读验证后使用原子替换；失败保留旧绑定。
- 删除移除绑定文件并回读不存在；不保留包含配置或密文的恢复副本。
- 正常服务不再要求命令行或环境变量输入 App ID、App Secret、租户。

## 配置会话合同

- 配置服务只绑定 `127.0.0.1` 随机空闲端口，每次只允许一个会话，十分钟超时。
- 启动器生成高熵一次性引导能力并自动打开浏览器；引导成功后立即失效，浏览器只持有 HttpOnly、SameSite=Strict 的短期会话 Cookie。
- 所有写入 POST 校验精确 Origin、会话状态和 CSRF 值；access log 关闭，响应禁用缓存和 Referrer。
- 保存、删除、取消或超时后关闭写入口并结束配置进程。

## 页面流程

### 创建与修改

1. 门户展示 Feishu Provider 的 `未配置` 或 `已配置` 脱敏状态。
2. 表单收集 App ID 和 App Secret；修改时不回显 Secret，默认保留，显式替换时要求两次输入一致。
3. 服务执行本地结构校验，使用 App ID/Secret 获取临时 `tenant_access_token`，再调用 `/open-apis/tenant/v2/tenant/query` 自动回读企业名称和 `tenant_key`；Token 只驻内存并立即丢弃。
4. 预览显示飞书实际返回的企业名称、`tenant_key`、非敏感差异和 Secret 的 `新增`、`保留` 或 `替换` 状态，生成绑定不可变草案摘要。
5. 管理员确认未变化草案后写入并回读；成功后配置进程退出，由同一启动脚本启动正常 OAuth 服务。
6. `tenant_key` 仍在真实用户 OAuth 回调中以飞书返回主体完成最终比对。

### 删除

1. 页面显示绑定路径、App ID、准入租户和“密钥已配置”，不显示 Secret 或密文。
2. 页面提示“本机删除不等于飞书远端撤销”。
3. 管理员输入 `删除本机部署绑定` 并确认不可变删除草案。
4. 服务删除绑定文件，回读文件不存在且状态为未配置；配置进程退出，不启动 OAuth 服务。

## 页面设计

- 主题：本机公共能力的“运行轨道”，面向负责部署和维护 Provider 的管理员，单一任务是安全建立或变更部署绑定。
- 色彩：深墨 `#0B1220`、冷灰画布 `#F4F7FB`、白色表面 `#FFFFFF`、轨道蓝 `#175CD3`、就绪绿 `#168A6A`、危险红 `#C4320A`。
- 字体：标题使用 Bahnschrift/Segoe UI Variable Display，正文使用 Segoe UI Variable Text/微软雅黑，标识和路径使用 Cascadia Mono/Consolas。
- 布局：左侧能力轨道编码 Provider 与状态，右侧承载单一配置任务；移动端改为顶部水平状态轨道。
- 记忆点：状态轨道不是装饰，而是始终显示 `门户 → Feishu → 配置/验证/就绪` 的真实阶段。
- 使用服务端渲染 HTML/CSS，不引入 SPA 或外部资源；支持键盘焦点、移动端和 reduced-motion。

## 实现切分

- `binding.py`：绑定模型、DPAPI 保护、路径解析、原子存取和回读。
- `admin.py`：短期会话、不可变草案、门户与 Feishu 配置页面、确认和删除流程。
- `feishu.py`：增加应用凭证验证与租户信息回读客户端，不缓存临时 Token。
- `cli.py`：增加 `configure`，并让 `preflight`、`serve` 默认从本机绑定加载。
- PowerShell 启动器：正常启动零输入；配置启动负责浏览器会话并按保存或删除结果决定是否启动服务。

## 验证

- 使用假 Secret protector 和临时目录覆盖创建、读取、原子修改、失败保留、真实删除和回读。
- Windows 上以非真实测试值执行 DPAPI 往返，证明只保存密文。
- 覆盖引导单次消费、Cookie、Origin、CSRF、超时、草案摘要变化、Secret 不回显与删除短语。
- 使用模拟 Feishu 客户端覆盖凭证成功、平台拒绝、超时和返回合同异常。
- 运行全部现有 OAuth 测试、字节码编译、锁文件校验、敏感模式扫描和浏览器视觉回读。
